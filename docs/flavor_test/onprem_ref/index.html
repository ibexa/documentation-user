On-premises HTML reference

This bundle is a fixture that stands in for a generated reference, such as the PHP API or REST API reference in the Developer Documentation. MkDocs copies such files verbatim instead of rendering them through the theme, and a generator overwrites them on every run, so they cannot carry front matter.

The delivery flavor is therefore declared in extra.flavor_only in mkdocs.yml. The on-premises build contains this bundle, and the SaaS build excludes it, together with its navigation entry.

The bundle spans several files and a nested directory on purpose, to confirm that one pattern covers a whole generated tree.
